# Ручные тесты этапа 0

## Цель проверки

Подтвердить, что окружение и базовый каркас проекта готовы к началу feature-разработки.

## Чек-лист

### 1. Проверка backend

1. Запустить backend локально.
2. Убедиться, что сервер поднимается без ошибок.
3. Открыть или вызвать базовый endpoint здоровья, если он реализован.
4. Подтвердить, что backend доступен на `http://localhost:8080`.

### 2. Проверка frontend

1. Запустить frontend локально.
2. Убедиться, что dev-сервер стартует без ошибок.
3. Открыть приложение в браузере.
4. Подтвердить доступность `http://localhost:5173`.

### 3. Проверка UI Kit

1. Перейти на `/ui-kit`.
2. Проверить, что страница открывается только в dev-среде.
3. Убедиться, что на странице есть базовые секции UI Kit.

### 4. Проверка тем

1. Переключить тему со светлой на тёмную.
2. Проверить, что цвета интерфейса реально меняются.
3. Обновить страницу и убедиться, что выбранная тема сохраняется, если persistence уже включён.

### 5. Проверка i18n

1. Переключить язык интерфейса на русский.
2. Переключить язык обратно на английский.
3. Убедиться, что переключение не ломает layout и состояние страницы.

### 6. Проверка базы данных

1. Подключиться к MongoDB.
2. Проверить наличие коллекций `cards`, `role_policies`, `admin_settings`, `decks`.
3. Убедиться, что в `cards` загружено `78` документов.
4. Проверить наличие стартовых политик для `seeker`, `adept`, `master`, `keeper`.
5. Проверить наличие дефолтной колоды.

### 7. Проверка конфигурации

1. Убедиться, что переменные окружения задокументированы.
2. Проверить, что секреты и runtime-файлы исключены из Git.

## Ожидаемый результат

Этап считается завершённым, если весь каркас запускается локально, база сидируется без ошибок, а UI Kit, темы и i18n готовы для дальнейшей разработки.
