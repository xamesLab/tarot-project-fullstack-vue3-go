# Этап 6. Деплой и запуск

## Цель этапа

Подготовить production-сборку, развернуть приложение, провести smoke tests и вывести MVP в рабочий режим с базовым мониторингом.

## Что должно быть реализовано

### 1. Pre-deployment

- проверить выполнение exit criteria этапа 5
- финализировать документацию проекта
- подготовить production env vars
- собрать backend binary
- собрать frontend production bundle
- подготовить production MongoDB и выполнить seed

### 2. Deployment

- развернуть backend на сервере
- развернуть frontend статику
- настроить reverse proxy для `/api`
- настроить раздачу `/uploads`
- подключить SSL

### 3. Smoke testing

- проверить health/stub endpoints
- проверить регистрацию и логин
- проверить генерацию чтений
- проверить загрузку изображений
- проверить theme switch и language switch
- проверить admin flow

### 4. Monitoring

- настроить сбор логов
- настроить basic uptime monitoring
- задокументировать процесс наблюдения за системой

### 5. Post-launch

- наблюдать за системой первые `24-48` часов
- оперативно устранять критические проблемы
- собирать обратную связь от первых пользователей

## Результат этапа

После завершения этапа MVP должен быть публично доступен, проходить smoke tests и иметь минимально достаточную операционную наблюдаемость.

## Критерии готовности

- production развертывание завершено
- SSL активен
- smoke tests пройдены
- мониторинг включён
- в первые сутки нет критических production-инцидентов
