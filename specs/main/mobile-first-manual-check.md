# Mobile-First Manual Check

Дата подготовки: 9 марта 2026.
Дата фиксации результата: 9 марта 2026.

## Цель
Ручная валидация критичных экранов на мобильных viewport.

## Рекомендуемые viewport
- `390x844` (iPhone 12/13/14)
- `360x800` (Android mid-range)

## Чек-лист
1. Login/Register:
   - поля и кнопки не выходят за экран;
   - кнопки кликабельны и имеют комфортный размер.
2. Dashboard:
   - карта дня и расклады читаемы;
   - кнопки `Reload Today` / `Generate New Spreads` не ломают layout;
   - текст лимитов читаем.
3. Settings:
   - поле timezone, селект темы, кнопка save корректно отображаются;
   - сообщения success/error не перекрывают форму.
4. Admin:
   - секции `Deck Themes`, `Role Policies`, `Assign Role` корректно перестраиваются в одну колонку;
   - формы можно заполнить без горизонтального скролла.
5. Общая навигация:
   - header/nav не ломаются;
   - переходы между `/dashboard`, `/settings`, `/admin` работают.

## Критерий прохождения
- Нет горизонтального скролла на ключевых экранах.
- Нет перекрытий текста/кнопок.
- Ключевые сценарии доступны без desktop-only действий.

## Результат
- Статус: `PASS`.
- Чек-лист пройден на целевых viewport.
