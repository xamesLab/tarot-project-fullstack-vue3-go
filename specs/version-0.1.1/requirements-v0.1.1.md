# Требования этапа v0.1.1 (MVP+)

## 1. Цель этапа
Расширить MVP до версии `0.1.1` с акцентом на:
- глобальные режимы интерфейса (язык/тема);
- отдельный полноценный контур админки;
- личный кабинет пользователя;
- работу с реальными изображениями колод и интерактивным открытием карт.

## 2. Функциональный скоуп

### 2.1 Режимы интерфейса (приоритет #1)
- Переключение языка интерфейса: `ru` / `en`.
- Язык по умолчанию: `ru`.
- Переключение цветовой схемы: `light` / `dark`.
- Тема по умолчанию: `light`.
- Выбранные режимы должны сохраняться между сессиями.
- Все новые экраны и доработки этапа должны учитывать i18n и theme tokens.

### 2.2 Админка (изолированный контур)
- Вход в админку только по прямому URL (через адресную строку).
- Интерфейс админки визуально отличается от основного приложения.
- В админке нет ссылок на разделы основного приложения.
- Минимальный набор страниц админки:
- `Пользователи`
- `Колоды / параметры колод`
- `Общие настройки`

#### Страница `Пользователи`
- Список всех пользователей.
- Пагинация: по `20` записей.
- Поля списка: `name`, `role`, `registeredAt`, `status`.
- Поддерживаемые статусы: `active`, `banned`, `freeze`.
- Фильтрация по `role` и `status`.
- Сортировка по дате регистрации.
- Поиск по имени: точное совпадение.

#### Страница `Колоды`
- Админ может создать новую колоду.
- При создании задается:
- имя колоды;
- изображение рубашки;
- изображения 78 карт.
- Допускается неполная загрузка карт.
- Статус колоды:
- `process`, если загружены не все обязательные изображения;
- `done`, если загружены все карты + рубашка.
- Список колод отображает:
- название;
- статус;
- имя пользователя, создавшего колоду.
- При выборе колоды открывается список загруженных карт.
- Можно догрузить отсутствующие карты и сохранить изменения.

### 2.3 Основное приложение: личный кабинет
- Добавить отдельную страницу `Личный кабинет`.
- Пользователь видит параметры профиля.
- Пользователь может изменять:
- `name`;
- `timezone`;
- выбранную колоду.
- Для выбора доступны только колоды со статусом `done`.

### 2.4 Отображение карт выбранной колоды
- Источник изображений для этапа: `specs/temp/card-image`.
- Источник метаданных карт: `specs/temp/mock/tarot-cards.json`.
- Имя файла изображения соответствует ключу карты:
- карты: по `id` (например, `22.jpg`);
- рубашка: `back.jpg`.
- Метаданные карты берутся из `list[]`:
- `id`, `name`, `key`, `arcana`, `interpretation`, `type`.

### 2.5 Поведение карточки на фронте
- При загрузке карта отображается закрытой (рубашкой).
- Название и описание карты скрыты.
- По клику карта переворачивается:
- показывается лицевая сторона;
- показываются `name` и `interpretation`.

## 3. Нефункциональные требования
- Mobile-first остается обязательным.
- Текущая auth/roles модель MVP не ломается.
- Для `0.1.1` допускается локальное файловое хранилище изображений (без внешнего object storage).
- Новые API и UI должны быть совместимы с текущим базовым маршрутизатором и guard-механизмом.

## 4. Критерии приемки
- Режимы `ru/en` и `light/dark` переключаются и сохраняются.
- Админка доступна только прямым URL и не содержит навигации в пользовательские разделы.
- Страница пользователей админки поддерживает пагинацию/фильтры/сортировку/точный поиск.
- Страница колод поддерживает создание, неполную загрузку, догрузку и автоматический статус `process/done`.
- В личном кабинете можно изменить профиль и выбрать колоду из `done`.
- В пользовательском раскладе карты показываются рубашкой и корректно переворачиваются по клику.

## 5. Зафиксированные допущения
- Поиск по имени реализуется как точное совпадение без подстроки.
- Точное совпадение реализуется регистронезависимо.
- Поля `name/interpretation` в `tarot-cards.json` на текущем этапе считаются основным контентом (RU).
- Английский режим на этапе `0.1.1` распространяется на UI-тексты приложения, не на локализацию смыслов карт.

## 6. Подтвержденные решения
- Публичный путь входа в админку: `/admin`.
- Режим `en` на этапе `0.1.1` локализует только интерфейс приложения.
- Контент карт (`name`, `interpretation`) остается исходным из каталога карт.
