# Ручные тесты этапа 4

## Цель проверки

Подтвердить, что `v0.1.1` готова как завершённая версия без deployment-части.

## Чек-лист

### 1. New AI user journey

1. Зарегистрировать или использовать обычного пользователя с доступом к AI.
2. Сгенерировать `Card of the Day`.
3. Открыть карту полностью.
4. Запросить AI-интерпретацию.
5. Сгенерировать `3-card spread`.
6. Открыть все карты.
7. Запросить AI-интерпретацию расклада.

### 2. Returning AI user journey

1. Открыть уже существующее чтение.
2. Проверить восстановление AI-результата.
3. Проверить поведение повторного запроса.
4. Проверить поведение на исчерпанном лимите.

### 3. Admin AI journey

1. Войти как `keeper`.
2. Проверить AI-метрики, если они входят в реализацию.
3. Отключить AI feature flag.
4. Проверить пользовательский интерфейс.
5. Вернуть AI feature flag обратно.
6. Проверить лимиты и настройки модели/prompt, если они входят в реализацию.

### 4. Responsive / i18n / themes

1. Пройти key screens на mobile.
2. Повторить на tablet.
3. Повторить на desktop.
4. Повторить критические сценарии в RU.
5. Повторить критические сценарии в EN.
6. Повторить в light и dark theme.

### 5. Error and resilience

1. Проверить timeout сценарий.
2. Проверить provider error.
3. Проверить невалидный или пустой AI-ответ.
4. Проверить, что UI не ломается и даёт retry path.

## Ожидаемый результат

Этап считается завершённым, если direct AI flow проходит критические сценарии, документация обновлена, а deployment остаётся отдельным следующим шагом, а не частью `v0.1.1`.
