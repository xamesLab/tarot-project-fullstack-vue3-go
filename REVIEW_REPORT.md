### Найденные замечания

1. **P2 — английский текст во время загрузки на русской локали.** В `frontend/src/app/router.tsx` заглушки `ProtectedRoute`, `KeeperRoute` и `Suspense` показывают `Loading…` независимо от выбранного языка. В проекте уже есть локализованные строки загрузки в `common.json`, но эти маршруты их не используют. Рекомендация: вынести отображение загрузки в небольшой компонент с `useTranslation('common')` и использовать его во всех маршрутах.
2. **P2 — серверные сообщения ошибок отображаются без перевода в админке.** `getAdminError` в `frontend/src/features/admin/shared.ts` возвращает `error.message` напрямую; backend/API может вернуть текст на английском, который показывается пользователю на русской локали. Рекомендация: сопоставлять известные коды ошибок с ключами локализации, а для неизвестных показывать локализованный fallback; исходные детали оставить для диагностики.
3. **P2 — неизвестные ошибки авторизации могут показываться на языке сервера.** `AuthModal.tsx` переводит несколько известных ошибок, но для остальных ошибок 4xx возвращает `error.message`. Рекомендация: добавить отображение по коду ошибки и локализованный общий fallback.

Раздел UI Kit доступен только в dev-сборке; его русскоязычные демонстрационные подписи не относятся к пользовательскому production-интерфейсу.

### Итог

Покрытие ключей локализации полное, но отдельные временные состояния и ошибки всё ещё могут нарушать язык интерфейса. В этой проверке исходный код не изменялся; тесты и приложение не запускались.

## Ревью изменений изображений TarotCard

Дата: 2026-10-20

### Замечание

1. **P2 — fallback-иллюстрации не совпадают с пропорциями нового контейнера.** В `tarot-card.css` контейнер `.tarot` по умолчанию имеет пропорции `2 / 3`. При отсутствии изображения или его ошибке `CardFace` / `CardBackVisual` переключаются на SVG с `viewBox="0 0 260 450"` (пропорции около `0,578`), который CSS растягивает на весь контейнер. Браузер сохраняет пропорции SVG и оставляет пустые полосы по бокам. Это ухудшает резервное отображение карты именно при сбое загрузки изображения. Рекомендация: согласовать пропорции fallback-контейнера с SVG либо адаптировать SVG под динамические пропорции; добавить проверку этого сценария.

### Остальные результаты

- В мок карты дня подключены оба PNG; пути собраны как локальные URL.
- Адаптация пропорций по naturalWidth/naturalHeight, заполнение рубашки с обрезкой по центру и радиус изображения согласованы с изменениями CSS.
- `git diff --check` прошёл без замечаний.
- На этапе первичного замечания тесты и браузерный прогон не запускались; после исправления проверки выполнены ниже. Других подтверждённых дефектов по просмотренному diff не найдено.

### Исправление замечания

Статус: **исправлено** (2026-10-20).

- Базовые пропорции `TarotCard` и SVG-заглушек согласованы: `260 / 450`. При недоступном или отсутствующем изображении лицо карты больше не оставляет боковые поля.
- SVG-рубашка использует `preserveAspectRatio="xMidYMid slice"`, поэтому при успешной загрузке лица с другими пропорциями рубашка заполняет контейнер с центральной обрезкой и без искажения рисунка.
- Добавлены проверки отсутствующих изображений, ошибки загрузки лица и ошибки рубашки при динамических пропорциях карты.
